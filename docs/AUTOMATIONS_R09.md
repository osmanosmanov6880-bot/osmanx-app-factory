# OSMANX R0.9 — автоматизации CRM

## Функция

- События: `client_created`, `visit_created`.
- Действие: создание задачи `todo`, связанной с гостем.
- Роли управления: admin/manager; staff не может читать и менять правила.
- Максимум 50 правил на CRM.
- История выполнения: 100 последних запусков; каждый запуск привязан к уникальному `(automation_id, event_key)`.
- `POST /api/automations`, `GET /api/automations`, `PATCH /api/automations/:id`, `DELETE /api/automations/:id`, `GET /api/automations/runs`.
- Все изменения защищаются существующими сессиями, CSRF и Origin-проверками.

## Консистентность

Событие и создаваемые задачи сохраняются в одной транзакции SQLite. Ошибка записи задач отменит создание клиента/визита. Повторная обработка того же события не создаст дубликата.

## Ограничения

Правила живут в SQLite-базе конкретного CRM-инстанса, поэтому попадают в backup/restore, но **не** переносятся в новые проекты через шаблоны / чистый ZIP. Новый экспорт имеет механизм правил, но без существующих настроек. Нет произвольного скриптинга или внешних вызовов; это намеренное ограничение для безопасности.

## Проверка

`npm test` — 17 Node-тестов включая транзакционный unit/integration и HTTP сценарии. `python tests/ui_automations_r09.py` — статическая визуальная проверка формы, без живого HTTP. Полный браузерный E2E к localhost в данной среде недоступен.
