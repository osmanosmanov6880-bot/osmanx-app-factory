# Change log R0.5 — Website Factory

- Добавлен blueprint `company-site`: новый тип `site` и отрасль `business`.
- Выполнена безопасная миграция CHECK constraint таблицы Studio `projects`; сохранены существующие CRM, страницы и внешние ключи.
- В Studio добавлены выбор типа проекта, параметры сайта, редактор публичных страниц, версии и ZIP-экспорт.
- Общий редактор поддерживает два набора блоков (CRM и сайт), серверные схемы валидируются разными контрактами.
- Добавлены SSR-сайт, начальные страницы, адаптивный публичный дизайн, темы, SEO-заголовки и безопасные ссылки.
- Добавлена независимая admin CMS (страницы, публикация, настройки, заявки и изменение статусов).
- Реализована защита первичного владельца внутри фабрики, локальная установка standalone с SETUP_TOKEN для публичного доступа.
- Добавлены публичная форма с валидацией, honeypot, базовый лимит запросов, SQLite таблица заявок.
- Добавлена отдельная резервная копия standalone-сайта, проверка целостности и восстановление из копии после остановки сервера.
- Добавлены manifest SHA256 и новый standalone ZIP без клиентских данных, паролей или сессий.
- Добавлены HTTP/SQLite/ZIP integration tests, миграционные тесты, backup/restore tests, статические интерактивные Chromium UI tests на 1440px/390px.
- Исправлен CSS `[hidden]` в CMS и добавлено подтверждение Studio владельца при первом входе.
- Защищены тип проекта от смены после создания и главная страница сайта от удаления.
- Добавлена синхронизация Studio → website с приоритетом локальных изменений CMS.

Всё остаётся локальным MVP. Развёртывание на публичный домен не выполнялось.
