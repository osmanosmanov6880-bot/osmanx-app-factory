## Ограничения перед коммерческой публикацией

Один владелец фабрики; сайт имеет одного/нескольких пользователей с одной ролью admin, но нет MFA/развитого жизненного цикла. Нет загрузки медиа и пользовательского HTML/JS (намеренное ограничение). Контактные данные клиентов требуют политики обработки/удаления, HTTPS, проверки хранения и резервирования. Лимит лидов в памяти процесса — недостаточная защита от публичного спама/ботнетов. Сайт без настроенного production URL закрыт от индексации. SSL, домен, DNS, облачный выпуск и отдельные отраслевые шаблоны — не выполнены. Экспорт сайта R0.5 не имеет контролируемого обновления кода с автоматической миграцией CMS после установки. При локальных изменениях CMS фабрика не перезаписывает опубликованный контент сайта.

**Следующий релиз R0.6:** единый визуальный дизайн-движок с layout/grid и медиа, поддержка типовых блоков коммерческих страниц, безопасные обновления standalone-сайтов с миграциями, полноценный браузерный real-HTTP E2E на доступной машине. Затем — отраслевые бизнес-шаблоны и облачная эксплуатация.
