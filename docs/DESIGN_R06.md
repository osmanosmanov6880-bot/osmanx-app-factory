# OSMANX APP FACTORY — R0.6 · ATELIER

## Цель переделки

R0.5 показывала три узкие колонки настройки одновременно. Текст в интерфейсе часто был 9–12 px; важные действия конкурировали с второстепенными. R0.6 меняет прежде всего **информационную архитектуру**, а не только цвета.

## Арт-дирекшн: Ivory / Obsidian / Forest

- Фон основной рабочей области: тёплая слоновая кость `#F5F4F0`.
- Навигация: графитово-зелёный `#161E1B`.
- Кнопки действий: глубокий хвойный `#234B3C`.
- Дополнительный акцент: приглушённая латунь `#BB9C66`.
- Основной текст: `#212821`, вспомогательный: `#57645B`.
- Без изображений, стоковых фотографий, тяжёлых градиентов или внешних шрифтов. Только реальные компоненты продукта.

## Изменения UX

1. **Главная:** больше не показываются одновременно три панели. Мастер `Основа → Возможности → Оформление` ведёт к результату по очереди.
2. **Выбор продукта:** две крупные кликабельные карточки с понятным назначением; за ними остаётся исходный выбор `crm|site`, совместимый с API.
3. **Библиотека функций:** модули расположены просторно, тексты объясняют бизнес-назначение. Обязательные пункты защищены.
4. **Резюме проекта:** справа видны выбранный тип, количество модулей и имя. На узком экране оно не мешает переходу между шагами.
5. **Готовые проекты:** первичное действие «Открыть» всегда видно; редактор, релизы, настройки и ZIP перенесены под «Управление».
6. **Редактор страниц:** три привычные зоны сохраняются, но контраст, размер подписей, поля и рабочий холст согласованы с новой системой.
7. **Data Studio, CRM и CMS:** применены те же контрастные поверхности, новые шрифтовые размеры и понятные русские обозначения.

## Технические гарантии

- Не менялась структура SQLite и API, пользователи и проекты миграции не требуют.
- Мастер управляется состоянием интерфейса; значение конфигурации передаётся в существующий `POST /api/studio/projects`.
- Поля и названия показываются через `textContent` или существующую HTML-экранизацию; пользовательский JS не исполняется.
- Упрощение проекта не изменяет рабочие модули, генерацию ZIP, авторизацию или ролевые проверки.
- Мобильные пользователи получают одну колонку и доступную кнопку «Продолжить» сразу под формой без декоративной сводки.
- Интерфейс учитывает `prefers-reduced-motion`, `:focus-visible`.

## Проверка

`npm run check`, `npm test` и `python tests/ui_premium_r06.py`.

Последний UI-тест запускает Chromium с моделируемыми API. Проверяет переходы, создание проекта, открытие дополнительных действий и отсутствие горизонтального переполнения на ширинах 1440 / 390 px. Это **не** полная браузерная проверка реального HTTP.

## Что не входит в R0.6

- Свободное пиксельное drag-and-drop конструирование сайтов.
- Подключение платёжного провайдера, новые отрасли, облачный деплой.
- Промышленная готовность и аудит безопасности.
