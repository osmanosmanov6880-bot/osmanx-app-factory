# CHANGELOG — R0.6 / ATELIER

- Полная русификация новых шагов и основных заголовков/описаний в фабрике, редакторе, CRM и CMS.
- Контрастная тема Ivory & Obsidian: просторные карточки, более крупные элементы управления и читабельные поля.
- Трёхшаговый мастер CRM/сайта с визуальным выбором типа продукта, интерактивной сводкой и мобильным упрощением.
- Карточки готовых проектов: одно основное действие и нативное раскрывающееся меню остальных операций.
- В редакторе русские названия состояний «Опубликовано / Черновик», редактируемые свойства и крупный холст.
- Дизайн распространён на Data Studio, самостоятельную CRM и CMS корпоративного сайта.
- Regression Node HTTP/SQLite/ZIP: 13 из 13, browser mocked API tests: см. `docs/TESTING.md`.
- Без изменений схем SQLite, модулей оплаты, бизнес-логики или маршрутов API.
